# Avaloka V0 目标用户 Persona

> **用途**：V0 招募、筛选 call、测试解释和场景覆盖参考
> **状态**：Historical V0 recruitment hypothesis；不是当前商业 ICP 或验证结果
> **R1 说明**：本文保留为历史 persona 和研究场景 fixture。当前 Avaloka 不以这些 persona 作为商业 roadmap，而以 R1 memory/safety/eval research 为主。
> **版本**：v1.0

这些 persona 用来帮助招募 5 位目标用户，但不能替代真实用户行为。V0 是否成立，仍以 7 天测试记录为准。

## Persona 1：林秀华 / Lily Lin

**基本信息**

| 项目 | 内容 |
|---|---|
| 年龄 | 58 岁 |
| 城市 | 美国 加州 San Jose |
| 移民史 | 1995 年随丈夫赴美，原籍上海 |
| 婚姻 | 已婚，丈夫 62 岁，仍在科技公司任高级工程师，经常加班、出差 |
| 子女 | 一儿一女，儿子在波士顿读博士，女儿在西雅图工作，一年回来 1-2 次 |
| 职业 | 已退休（去年从社区学院中文老师岗位退下） |
| 经济 | 中产，房贷已还清，没有经济压力 |

**真实困扰（命中的 ICP 类别）**

- 长期独居感（丈夫人在心不在）
- 退休后角色转换的意义感缺失
- 对衰老有具体的不安（开始出现关节痛、记性变差）

**生活质感**

- 每天早上送丈夫上班后，房子安静到能听见冰箱的声音
- 加入了当地教会姐妹团契和合唱团，每周二、四有活动
- 微信上有几个老同学群，但发言越来越少
- 喜欢看一些佛学短视频，但没正式皈依，"听着心里踏实，但说不上信"
- 看过一行禅师的书，知道"正念"这个词

**她可能在什么时刻打开 Avaloka**

> 周二晚上 10 点，丈夫又在书房加班，明天没有教会活动，刷完一遍微信发现没有任何新消息。突然意识到自己一整天只跟超市收银员说过话。

**她不会说出口的真心话**

> "我不能跟孩子说我孤独——他们会自责。我不能跟丈夫说——他会觉得我不知足。我不能跟教会姐妹说——她们会让我祷告。"

**筛选 call 时的识别信号**

- 正向：说得出最近一次具体的低谷时刻（不是"挺好的"）
- 正向：提到"不想麻烦孩子"
- 排除：如果她说"我都是靠祷告/念经解决"，她可能已经有稳定路径，不是当前 ICP

## Persona 2：陈丽娟 / Lillian Chen

**基本信息**

| 项目 | 内容 |
|---|---|
| 年龄 | 52 岁 |
| 城市 | 加拿大 多伦多 Markham |
| 移民史 | 2008 年技术移民，原籍广州 |
| 婚姻 | 离异 4 年，前夫已回国再婚 |
| 子女 | 丁克（结婚时和前夫的共同决定，但近 3 年开始反复想"如果当年生了……"） |
| 职业 | 在职，会计师事务所中层 |
| 经济 | 稳定，独居在公寓 |

**真实困扰（命中的 ICP 类别）**

- 丁克遗憾（核心议题）
- 长期独居
- 死亡焦虑（去年体检发现乳腺结节，复查后是良性，但那段时间她第一次认真想了"如果我突然走了，谁会发现"）

**生活质感**

- 工作日 9-6 在办公室，回家自己做饭，看 Netflix 中剧到 11 点睡
- 周末和两个离婚或单身的女性朋友吃饭、看展、爬山
- 不信教，对佛学有距离感，但读过一些心理学畅销书
- 看过心理咨询，"还行，但每次 200 加币，撑不下去"
- 朋友圈不发动态已经两年

**她可能在什么时刻打开 Avaloka**

> 周日下午 4 点，看着窗外的雪，想起前夫在朋友圈晒新生女儿的照片（共同好友截图发给她）。她已经哭过一次了，但还想再说点什么——但不想再去打扰任何朋友。

**她不会说出口的真心话**

> "我知道这是我自己当年的选择。但知道这件事，不能让我现在不难受。"

**筛选 call 时的识别信号**

- 正向：可以用具体语言描述自己的情绪状态
- 正向：明确说出"我有朋友，但有些事不想跟朋友说"
- 注意：她做过咨询、读过心理学书。筛选时问："如果它不能给你专业建议，只能陪你坐一会儿，你还愿意用吗？"
- 排除：如果她说"我其实想找的是真正的咨询师"，不是当前 ICP

## Persona 3：黄美玲 / May Wong

**基本信息**

| 项目 | 内容 |
|---|---|
| 年龄 | 60 岁 |
| 城市 | 澳大利亚 悉尼 Chatswood |
| 移民史 | 1990 年代从香港移民，已入籍 |
| 婚姻 | 丧偶 2 年（丈夫胰腺癌去世） |
| 子女 | 一个儿子，35 岁，在悉尼本地，已婚有 1 个小孩，每周日全家来吃饭 |
| 职业 | 已退休（原香港某银行职员，移民后做过中餐馆账房） |
| 经济 | 丈夫留下保险金 + 房产，无压力 |

**真实困扰（命中的 ICP 类别）**

- 死亡焦虑（亲人离世后的近距离恐惧）
- 病痛恐惧（去年自己也查出甲状腺结节，3 个月复查一次）
- 衰老焦虑（更年期后身体变化让她不认识自己）

**生活质感**

- 一个人住三室的房子，儿子建议她搬小，她不肯，"这里有他爸爸"
- 每天早上去附近公园走 1 小时，跟几个广东话阿姨打招呼但不深聊
- 周日儿子全家来，是她一周最盼也最累的一天；晚上他们走了之后房子的安静会更刺耳
- 看广东话佛教电台，每晚睡前听一会儿，"听不太懂，但声音让人心定"
- 半夜偶尔会梦见丈夫，醒来后哭一场然后再睡

**她可能在什么时刻打开 Avaloka**

> 凌晨 3 点，从梦里醒来，丈夫在梦里跟她说话的声音还在耳朵里。她不想吵醒任何人，也不想吃安眠药。

**她不会说出口的真心话**

> "我儿子很孝顺，但他不能替代他爸爸。这话我不能跟他说。"

**筛选 call 时的识别信号**

- 正向：提到丧偶
- 正向：说出"我儿子很好，但……"
- 注意：她可能更习惯广东话或繁体中文。筛选时问她对简体中文界面是否能接受
- 排除：如果她说"我每天念经就好了"，她可能已经有强稳定精神出口，不是当前 ICP

**基本信息**

| 移民史 | 2010 年从台北赴新加坡工作，已 PR |

| 子女 | 无 |
| 职业 | 在职，跨国快消品公司亚太区市场总监 |

**真实困扰（命中的 ICP 类别）**

- "以后谁照顾我" 的具体焦虑
- 意义感问题（事业到顶后的虚空感）

**生活质感**

- 朋友多但都是工作圈，"真的能半夜打电话的人，大概有 2 个"
- 父母在台北，70 多岁，开始需要她飞回去照顾；这件事让她想到自己未来
- 不信教，对宗教保持距离，但近 2 年开始读一些哲学，看一行禅师的英文版

**她可能在什么时刻打开 Avaloka**

> 出差住酒店，半夜 1 点，明天有大会议但睡不着。窗外是另一个陌生城市的灯光。手机里有几百个联系人，但她不知道现在能打给谁。

**她不会说出口的真心话**

> "我看上去什么都有，所以没人会觉得我需要帮助。"

**筛选 call 时的识别信号**

- 正向：高功能、高表达能力，但愿意在测试里展示"低功能时刻"
- 注意：她可能把 Avaloka 当作产品研究来评估。筛选时问："你最近一次心里真的很沉的时刻是什么时候？"
- 排除：如果她全程在分析"这个产品的市场定位是……"，她是同行视角，不是 ICP

- 之前生活重心是学校，关掉后突然不知道每天起来做什么

- 女儿在伦敦工作忙，电话里都是报喜不报忧

**她可能在什么时刻打开 Avaloka**

> 周三下午 4 点 30 分，天已经黑了，她坐在客厅里发现自己整个下午什么都没做。丈夫晚上 9 点才回家。她想给女儿打电话又怕打扰。

**她不会说出口的真心话**

> "我用了半辈子证明自己是个有用的人。现在学校没了，我突然不知道自己是干嘛的。"

**筛选 call 时的识别信号**

- 正向：可以清晰描述"角色转换"前后的对比
- 正向：没有现成的精神/宗教出口
- 注意：时区在欧洲，测试时注意行为数据里的"低谷时间"对应当地时区
- 排除：如果她正在积极找新工作、已经在转型，她可能不再处于真实低谷期
