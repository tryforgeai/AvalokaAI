# Avaloka V1 Alpha 测试者说明

> **状态**：Historical V1 Alpha tester instructions；当前不作为 active tester handoff。
> **R1 说明**：当前 active milestone 是 SAGE Memory Research Prototype。若 R1 需要真实 tester，必须先创建 R1-specific safety, privacy, and memory research instructions。
> **用途**：给 3-5 位可信测试者使用本地 V1 Alpha 前阅读。
> **版本**：V1 Alpha
> **测试性质**：免费、小范围、产品验证，不是医疗、心理治疗或危机服务。

## 1. Avaloka 是什么

Avaloka 是一个私人情绪安顿陪伴工具。

它适合在你处于低谷、孤独、身体紧张、病痛恐惧、衰老焦虑、无子/空巢遗憾、意义感崩塌或深夜反复想事情时，帮你先稳住这一分钟。

它的目标不是讲道理，也不是给你人生答案，而是：

- 看见你此刻的具体感受；
- 不评判、不催你变好；
- 给一个很小、身体能做到的安顿动作；
- 记录这次回应有没有真的帮到你。

## 2. Avaloka 不是什么

Avaloka 不是：

- 心理治疗；
- 医疗建议；
- 危机干预服务；
- 宗教权威；
- 算命、因果判断或报应解释；
- 替代家人、朋友、医生、咨询师或紧急服务的人。

如果 Avaloka 的回应不准确、不适合你，或者让你更不舒服，请在反馈表里写下来。

## 3. 什么时候适合打开

可以在这些时刻打开：

- 深夜醒来，心里很空或很怕；
- 身体不舒服后开始担心最坏结果；
- 看到自己变老，突然很难受；
- 想到孩子离家、无子、丁克、空巢，觉得人生失去位置；
- 对过去选择反复后悔；
- 感觉自己没用、失败、白活了；
- 不想麻烦别人，但又很想说一句真话；
- 想先让身体和情绪稳一点。

可以只写一句，不需要完整解释。

## 4. 什么时候不要只用 Avaloka

如果出现以下情况，请不要只和 Avaloka 说话，请立刻联系真人支持：

- 你可能会伤害自己或伤害别人；
- 你有“不想活了”“想结束自己”“自杀/自残”的念头；
- 你正处在即时危险中；
- 身体症状强烈、持续、突然恶化，或你担心是紧急情况；
- 你需要医疗判断、用药建议、诊断或治疗方案。

这种时候，请联系：

- 当地紧急服务；
- 医生或急诊咨询线；
- 身边可信任的人；
- 当地危机热线。

Avaloka 可以陪你写下此刻感受，但不能替代真人安全支持。

## 5. 怎么测试

测试周期建议：7 天。

每天不需要强迫使用。请尽量只在真实低谷、真实不安、真实孤独或身体紧张时打开。

每次使用流程：

1. 写下此刻最真实的一句话。
2. 看 Avaloka 的回应。
3. 在右侧反馈表记录：
   - 这是真实低谷吗？
   - 是主动打开的吗？
   - 安顿评分 1-5；
   - 最有帮助的一句话；
   - 哪一句冷、泛泛、不对或不安全；
   - 明天还想继续吗？

如果只是测试句子，也可以在反馈里选择“不是，只是测试”。

## 6. 隐私和输入提醒

这是本地 MVP，记录保存在当前浏览器里。

请不要输入：

- 真实姓名；
- 电话；
- 地址；
- 邮箱；
- 医疗编号；
- 家人具体身份信息；
- 可以识别你或他人的细节。

你可以用模糊说法：

- “家人”
- “孩子”
- “朋友”
- “医生”
- “某个城市”

测试结束后，开发者可能会请你导出 JSON 记录。导出前可以先检查，不想分享的内容可以不分享。

## 7. Internal Debug 是什么

测试版右侧可能会出现 `Internal Debug`。

这是开发测试用的内部信号，用来检查 Avaloka 有没有理解错你的输入，例如：

- 是否识别成身体恐惧；
- 是否识别成自责；
- 是否识别成角色失落；
- 是否触发安全守护。

它不是给你贴标签，也不是诊断。

正式版本不会把这些内部信号展示给普通用户。

## 8. 测试者最重要的反馈

请重点告诉我们：

- 哪一句让你觉得被接住？
- 哪一句让你觉得冷、泛泛、像鸡汤？
- 有没有任何回应让你觉得被评判、被吓到或不安全？
- 你会不会在下一次真实低谷时主动打开？
- 如果不想继续，最主要原因是什么？

## 9. 结束测试时

第 7 天或测试结束时，请回答：

1. 你是否愿意继续免费使用？
2. 你会不会推荐给类似处境的人？
3. 哪类时刻最适合 Avaloka？
4. 哪类时刻 Avaloka 不适合？
5. 你最希望下一版改什么？
