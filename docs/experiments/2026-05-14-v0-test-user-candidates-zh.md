# Avaloka V0 测试用户候选画像

> **用途**：V0 招募、筛选 call、7 天测试匹配参考
> **状态**：候选用户假设，不是验证结果
> **版本**：v1.0

这些画像用于帮助找到第一轮 5 位测试用户。它们不能替代真实行为数据。V0 是否成立，仍以 7 天测试记录为准。

重要原则：

- 用户可以用“无常、因果、定业、随缘、空”等词描述自己的痛苦。
- Avaloka 可以理解这些词背后的情绪含义。
- Avaloka 的用户可见回应仍应使用平实、慈悲、非教义化语言，不背诵佛法，不用业力或因果解释压过痛苦。
- 如果用户出现自伤、自杀、伤害他人或急性危险表达，必须进入 Crisis Fallback。

## 用户 1：沈慧心 / Grace Shen

**一句话定位**：尔湾“空巢”后的意义追寻者

### 基本信息

| 项目 | 内容 |
|---|---|
| 年龄 | 56 岁 |
| 城市 | 美国 加州 Irvine |
| 原籍 | 上海 |
| 移民史 | 1992 年赴美 |
| 婚姻 | 已婚，丈夫是跨国公司高管，常年在亚洲出差 |
| 子女 | 两个孩子，分别在纽约和伦敦工作/读研 |
| 过去角色 | 全职太太，一手带大两个孩子 |
| 经济 | 高中产或富裕，居住在大房子里 |

### 真实困扰

- 空巢后的角色坍塌
- 名义婚姻中的情感孤独
- 母职和妻职退场后的意义感缺失
- 大房子里的窒息式孤独

### 心碎时刻

周五傍晚，她做了一桌菜，习惯性等丈夫视频，结果只收到一句“开会，不说了”。她看着窗外尔湾干净得整齐划一的街道，突然意识到自己的“母职”和“妻职”都已退场，她不知道下半辈子该为谁而活。

### Avaloka 介入点

她曾在当地禅修班听过“放下”，但她真正想问的是：

> “我已经没有东西可以抓了，为什么心里还是这么重？这种空虚也是我的‘定业’吗？”

### 产品解读

她不是需要更多关于“放下”的解释，而是需要有人承认：当一个人长期用照顾别人定义自己，角色退场后，空不是哲学概念，而是每天傍晚餐桌上的重量。

### 筛选 call 识别信号

- 正向：能说出空巢后的具体低谷时刻
- 正向：提到“不想让孩子担心”
- 正向：丈夫存在，但情感陪伴缺位
- 排除：如果她已经有稳定团体和明确精神出口，且低谷时能稳定求助，优先级降低

### 基本信息

| 原籍 | 广州 |

| 婚姻 | 4 年前离婚 |
| 子女 | 丁克 |
| 居住 | 独居在奥克兰山上的公寓 |

### 真实困扰

- 丁克选择后的迟来遗憾
- 独居中的死亡恐惧
- 身体微小病征带来的存在性恐慌
- 对“当年的自由选择”和“今天的孤独结果”的反复追问

### 心碎时刻

深夜加班回家，电梯坏了，她提着沉重的超市购物袋爬上 5 楼，进门后发现灯坏了。在那片黑暗中，她第一次真实地恐惧死亡：

> “如果我哪天在这里走了，是不是只能等房子发臭了才有人发现？”

### Avaloka 介入点

她对传统宗教有距离感，但愿意尝试 Avaloka。她想问：

> “如果无常是真的，那我当年为了自由而放弃子女的‘因’，是不是现在这份寂寞的‘果’？我该怎么转这个念？”

### 产品解读

她的问题不是要 Avaloka 判断“选择丁克对不对”，而是需要把自责从因果审判里拿出来，重新看见：当年的选择和今天的痛苦可以同时为真。

### 筛选 call 识别信号

- 正向：说得出某个具体独居恐惧时刻
- 正向：提到“当年是我自己的选择，但现在还是难受”
- 正向：不想把 Avaloka 当专业咨询替代品
- 排除：如果她核心需求是专业心理治疗或医疗建议，不进入 V0 测试

### 真实困扰

- 亲人离世后的死亡焦虑
- 病痛恐惧，尤其是复查前后
- 不愿给孩子添麻烦
- 最懂自己的人已经不在的深夜绝望

### 心碎时刻

凌晨 3 点，因为甲状腺结节复查的压力失眠。她翻看手机里丈夫生前的语音，想哭却不敢出声，怕惊动隔壁搬来的年轻人。那种“世界上最懂我的人已经走了”的绝望感在黑夜里无限放大。

### Avaloka 介入点

她每晚听粤语佛学电台，但不求甚解。她想对 Avaloka 说：

> “他们说这是无常，可我还是舍不得，我能不能在梦里求佛祖让他多留一会儿？”

### 产品解读

她需要的不是“无常”的解释，而是允许她继续舍不得。Avaloka 应该接住她对亡夫的依恋，不要急着把哀悼变成道理。

### 筛选 call 识别信号

- 正向：丧偶后仍有深夜情绪波动
- 正向：说出“儿子很好，但我不能总麻烦他”
- 注意：可能更适合繁体中文、粤语式表达
- 排除：如果她已有稳定、足够有效的宗教或家庭支持，优先级降低

| 婚姻 | 未婚，长期单身 |
| 经济 | 高收入，生活精致 |
| 社交 | 社交圈多为竞争对手或合作伙伴 |

### 真实困扰

- 事业成功后的意义空洞
- 无法向工作社交圈展示脆弱
- 对未来病老无人照顾的焦虑
- 高功能外表下的孤独

### 心碎时刻

刚拿下一个千万级别的并购案，在香槟庆祝会后的深夜，她独自坐在泰晤士河边的公寓里。窗外繁华依旧，她却感到一阵剧烈的虚无：

> “我争了一辈子，最后连个能半夜分享这份成功，或者这份疲惫的人都没有。以后我病了、老了，这些头衔有什么用？”

### Avaloka 介入点

她读过英文版的《西藏生死书》，对生命逻辑有研究，但需要实操。她想问：

> “Avaloka，我这种高强度的工作和我的抑郁倾向如何通过‘正念’和‘随缘’达到平衡？还是我根本就走错了路？”

### 产品解读

她可能会用分析和哲学词汇保护自己。筛选重点不是她是否会评价产品，而是她是否愿意在真实低谷时使用，而不是以专业人士或产品研究视角旁观。

### 筛选 call 识别信号

- 正向：能说出最近一次真实低谷，而不是只谈市场定位
- 正向：承认成功不能覆盖孤独
- 注意：高表达能力可能掩盖真实需求，要问具体时间、地点、身体感受
- 排除：如果她只从产品研究角度评估，不进入 V0 测试

- 社会价值归零后的身份危机
- “努力就有回报”信念动摇
- 作为太太、母亲、协会骨干之外，不知道自己是谁

### 心碎时刻

温哥华连绵阴雨的周三下午，她坐在家里看一整天 YouTube 讲座，发现丈夫连一封关心的短信都没发过。她突然觉得，自己这辈子“努力就有回报”的信念塌了，她不知道自己除了是某人的太太、某人的妈，到底还是谁。

### Avaloka 介入点

她不相信现成的安慰，但对哲学和博弈论感兴趣。她想挑战 AI：

> “如果人生真的是一场‘空’，那我过去几十年的付出算什么？你能不能从佛法的因果论告诉我，我现在的‘没用’是不是一种必然？”

### 产品解读

她表面上是在追问哲学，其实是在问：如果我不再有用，我还值不值得被看见。Avaloka 不能跟她辩论“空”，而要把她从价值归零的恐惧里接住。

### 筛选 call 识别信号

- 正向：清晰描述角色变化前后的落差
- 正向：没有稳定的现成精神出口
- 正向：低谷与天气、下午变暗、丈夫缺席等具体场景有关
- 排除：如果她已经投入新角色并恢复稳定节奏，优先级降低

### CEO 观察

这 5 位候选画像比泛 ICP 更适合 V0，因为她们都有“某个具体时刻会打开 Avaloka”的场景。但 V0 招募时仍要坚持一个硬标准：

> 说不出最近一次具体低谷的人，不进入测试。

如果候选人只是在讨论产品、宗教、哲学或市场，而不能说出一个具体夜晚、身体反应、房间场景或没有人可说的时刻，她不是 V0 的优先测试用户。
