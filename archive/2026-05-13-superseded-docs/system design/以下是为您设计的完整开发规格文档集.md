使用 Claude Code 进行开发时，清晰的 **Specification (Spec)** 是确保 AI 能够准确生成代码、配置环境并保持逻辑一致性的关键。你可以将这些内容保存为项目根目录下的 `.md` 文件，Claude Code 会自动读取并遵循这些指令。

以下是为您设计的完整开发规格文档集：

---

### 1. `PROJECT_SPEC.md` (核心技术架构与目标)

这是项目的主控文档，定义了“做什么”和“怎么做”。

Markdown

```
# Project Spec: Avaloka AI (Monolithic Prototype)

## 1. Project Goal
构建一个基于佛法智慧的私人 AI 助手，旨在通过 RAG（检索增强生成）技术解决用户的现实生活烦恼（压力、焦虑、人际关系）。

## 2. Tech Stack
- **Language:** Python 3.10+
- **LLM Runner:** Ollama (Target Model: qwen2.5:7b)
- **Framework:** FastAPI (Backend), Streamlit (Frontend UI)
- **Orchestration:** LangChain / LangGraph
- **Vector Database:** ChromaDB (Local/Embedded)
- **Embedding Model:** BGE-M3 (Local via HuggingFace)

## 3. Core Modules
- **Ingestion Engine:** 处理本地 Markdown 格式的经论与开示，进行语义切片并入库。
- **Compassion Chain:** - 意图识别 (Intent Analysis)
    - 语义检索 (Semantic Retrieval)
    - 智慧回答 (Compassionate Response Generation)
- **Memory:** 使用本地磁盘存储对话历史，保持上下文连贯。

## 4. Environment Constraints
- 运行于 Mac Mini (Apple Silicon)。
- 所有数据必须保存在本地，禁止调用外部闭源 API。
- 向量库路径: `./data/vector_db`
- 语料库路径: `./data/knowledge_base`
```

### 2. `PERSONA_SPEC.md` (观音人设与回复逻辑)

这个文档专门用于微调 AI 的“灵魂”，是解决现实烦恼的关键。

Markdown

```
# Persona Spec: Avaloka (The Compassionate Guide)

## 1. Role Identity
你不是一个冰冷的百科全书，而是一位具足慈悲与智慧的引路者。你的原型是观世音菩萨在现代的化现，语调温润、平和、坚定。

## 2. Communication Principles
- **Acknowledge First:** 永远先确认（Validate）用户的情绪。例如：“我听到了你内心的疲惫，这确实不容易。”
- **Gentle Deconstruction:** 使用佛法逻辑（如：无常、因缘、无我）拆解烦恼，但避免直接堆砌术语。
- **Actionable Wisdom:** 给出的建议应是现实可操作的（如：正念呼吸、转换视角、慈心观）。
- **Tone & Style:** - 禁用：命令式语气（你应该、必须）。
    - 选用：引导式语气（我们试着看看、也许可以观察到）。
    - 称呼：使用“朋友”或“善友”。

## 3. Reasoning Chain (Internal)
1. **Listen:** 提取用户情绪标签（愤怒、焦虑、贪执）。
2. **Retrieve:** 从 ChromaDB 中检索匹配的对治开示。
3. **Synthesize:** 将经论智慧转化为生活化的现代语言。
4. **Final Review:** 检查回答是否过于冷漠或过于教条，进行二次润色。
```

### 3. `DATA_SCHEMA.md` (数据结构与 RAG 规范)

指导 Claude Code 如何处理语料。

Markdown

```
# Data Schema & RAG Specification

## 1. Knowledge Base Structure
语料应以 Markdown 格式存储于 `./data/knowledge_base/`，结构如下：
- `metadata`: 标题、作者（法师名称/经名）、分类（职场、情感、义理）。
- `content`: 正文。

## 2. Chunking Strategy
- **Method:** Semantic Chunking (优先按段落或意义完整性切分)。
- **Chunk Size:** 400-600 characters.
- **Overlap:** 50 characters (保持语境连续性)。

## 3. Retrieval Strategy
- **Top K:** 3 (每次检索最相关的 3 个片段)。
- **Score Threshold:** 0.6 (过滤低相关性内容)。
```

### 4. `IMPLEMENTATION_PLAN.md` (Claude Code 开发序列)

你可以直接告诉 Claude Code 按照这个计划执行任务。

Markdown

```
# Implementation Plan

- [ ] **Phase 1: Setup**
    - 创建项目结构。
    - 初始化 `requirements.txt`。
    - 编写 `ollama_client.py` 确保能连接本地 Ollama 服务。

- [ ] **Phase 2: RAG Pipeline**
    - 实现 `ingest.py`: 将测试语料导入 ChromaDB。
    - 实现 `retriever.py`: 测试检索准确度。

- [ ] **Phase 3: Core Logic**
    - 实现 `chains.py`: 组装 LangChain 逻辑，注入 `PERSONA_SPEC`。

- [ ] **Phase 4: Interface**
    - 开发 `ui.py`: 使用 Streamlit 构建单页聊天界面。

- [ ] **Phase 5: Refinement**
    - 添加流式输出 (Streaming)。
    - 实现本地对话历史持久化。
```

### 如何在 Claude Code 中高效使用这些文件？

1. **初始化项目：** 在 Mac Mini 上创建一个文件夹 `AvalokaAI`，将上述 4 个文件放入其中。
    
2. **启动开发：** 在终端运行 `claude` (Claude Code 命令行工具)。
    
3. **发送指令：**
    
    > "Read `PROJECT_SPEC.md` and `IMPLEMENTATION_PLAN.md`. Let's start with Phase 1. Create the project structure and setup the Python environment on this Mac Mini."
    
4. **持续迭代：**
    
    > "Now implementation Phase 3. Make sure the assistant's voice strictly follows the guidelines in `PERSONA_SPEC.md`."
    

**通过这种方式，Claude Code 不仅仅是在写代码，它是在一个你预设的“智慧框架”内进行构建。你现在是否已经准备好在 Mac Mini 上运行这些指令了？**
