为了让你的 Mac Mini 真正变身成为“Avaloka AI”的法座，这里是基于 **Claude Code** 开发模式的从零到一详细指令清单。

---

### 第一阶段：准备 Mac 本地基座 (耗时约 15 分钟)

这是所有后续开发的前提，确保你的 Mac Mini 拥有最先进的开发者工具。

|**步骤**|**操作内容**|**终端命令 (Terminal)**|
|---|---|---|
|**1. 安装 Homebrew**|Mac 的包管理神器|`/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`|
|**2. 安装基础工具**|Git, Node.js (Claude Code 依赖)|`brew install git node`|
|**3. 安装 uv**|极速 Python 环境管理工具|`curl -fsSL https://astral.sh/uv/install.sh|
|**4. 安装 Ollama**|本地大模型运行引擎|`brew install --cask ollama`|
|**5. 安装 Claude Code**|你的 AI 开发搭档|`npm install -g @anthropic-ai/claude-code`|

**验证步骤：**

在终端输入 `ollama pull qwen2.5:7b`。下载完成后，输入 `ollama run qwen2.5:7b`，随便问一个问题，如果能秒回，说明你的 GPU 加速已就绪。输入 `/bye` 退出。

---

### 第二阶段：项目初始化与 Spec 注入

在你的文档目录下创建项目，并将我们之前定义的“图纸”喂给 Claude。

#### 1. 创建目录结构

Bash

```
mkdir -p ~/AvalokaAI/data/{vector_db,knowledge_base}
cd ~/AvalokaAI
touch PROJECT_SPEC.md PERSONA_SPEC.md DATA_SCHEMA.md IMPLEMENTATION_PLAN.md
```

#### 2. 写入 Spec 内容 (关键)

使用终端编辑器（如 `nano` 或直接用 TextEdit）将之前回复中给出的四大文档内容分别填入对应的 `.md` 文件中。这对 Claude Code 能够准确理解你的意图至关重要。

---

### 第三阶段：使用 Claude Code 驱动开发

现在，打开 **Claude Code**，它是你的主程序员。

#### 1. 启动 Claude 并对齐

Bash

```
claude
```

进入对话后，输入第一条指令：

> “我已经准备好了所有的 Spec 文档。请读取当前目录下所有的 .md 文件，并根据 `IMPLEMENTATION_PLAN.md` 告诉我你准备如何开始 Phase 1。”

#### 2. Phase 1：环境与安全兜底 (详细命令)

Claude 确认后，你可以下令：

> “执行 Phase 1。请使用 `uv` 初始化 Python 3.10+ 环境。创建一个 `requirements.txt`（包含 fastapi, langchain, chromadb, ollama, pydantic-settings）。接着编写 `security_config.py`，实现一个基于正则的‘危机词库’检测函数，并确保所有 API 仅限本地访问。”

**Claude 会自动执行：**

- `uv venv`
    
- `uv pip install -r requirements.txt`
    
- 生成文件。
    

#### 3. Phase 2：构建 RAG 知识库

> “执行 Phase 2。编写 `ingest.py`。要求：使用 `langchain` 的 `SemanticChunker` 对 `./data/knowledge_base` 下的文件进行切片，使用 `BAAI/bge-m3` 作为 Embedding 模型，并将向量存入 `./data/vector_db`。请顺便在 `./data/knowledge_base` 里创建一个示例 Markdown 文件，内容是一段关于‘职场焦虑’的佛法开示。”

#### 4. Phase 3：核心逻辑（观音人设）

> “执行 Phase 3。这是最重要的步骤。编写 `logic.py`，根据 `PERSONA_SPEC.md` 实现一个对话链。要求：1. 先调用危机检测函数；2. 从向量库检索 Top 3 内容；3. 注入系统提示词并调用本地 Ollama。必须包含对话历史记忆功能。”

#### 5. Phase 4：界面开发

> “执行 Phase 4。编写 `ui.py`。使用 Streamlit 建立前端。要求：具备禅意简约风格，支持 Markdown 渲染（用于显示经文），并实现流式输出 (Stream)。”

---

### 第四阶段：运行与测试

当 Claude 完成上述代码编写后，你可以通过以下命令在本地启动你的应用：

Bash

```
# 激活环境
source .venv/bin/activate

# 启动 Streamlit
streamlit run ui.py
```

### 安全性与完整性自查命令

在开发过程中，随时可以使用这些命令检查你的系统：

1. **检查本地端口：**
    
    `netstat -vanp tcp | grep 11434`
    
    (确保只有 `127.0.0.1` 在监听)
    
2. **检查 Python 漏洞：**
    
    `uv pip install pip-audit && pip-audit`
    
3. **验证 GPU 使用率：**
    
    在应用运行时，按 `Cmd + Space` 输入 "Activity Monitor"，查看 "GPU History"。
