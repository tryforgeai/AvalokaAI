为了确保系统的稳健性、安全性和慈悲引导的深度，我们将之前的安全审计和技术优化点整合进了这个更新版的开发蓝图。

### 更新后的 6 周开发计划 (含安全与工程优化)

#### 第一周：基础设施与安全加固 (Setup & Hardening)

- **环境搭建：** 在 Mac Mini 上部署 Ollama (Qwen2.5-7B) 和 `uv` (Python 环境)。
    
- **安全加固：** * 配置 Ollama 仅监听本地回环地址 (`127.0.0.1:11434`)。
    
    - 设置 `.env` 环境变量文件，隔离所有本地路径和配置。
        
    - 安装 `pip-audit` 进行依赖项漏洞扫描。
        
- **指令：** 让 Claude Code 编写 `ollama_client.py` 并包含基础的连接超时处理机制。
    

#### 第二周：深度语料处理与元数据标注 (Advanced Ingestion)

- **语料准备：** 搜集经文与大德开示（如《工作好修行》）。
    
- **数据清洗（数据卫生）：** * 使用语义切片（Semantic Chunking）替代固定长度切片。
    
    - **元数据增强：** 为每个切片添加标签（如：情绪类别：焦虑；对治方法：无常；来源：圣严法师）。
        
- **入库：** 将处理后的数据存入本地 ChromaDB。
    

#### 第三周：核心逻辑、记忆与安全熔断 (Logic & Safety Firewall)

- **对话记忆：** 实现 `ConversationSummaryBufferMemory`，自动总结长对话，防止上下文溢出。
    
- **安全熔断逻辑：** * 在后端加入**危机检测层**。如果识别到自残、极度抑郁等高风险词汇，强制输出预设的心理干预话术。
    
    - 实现输入清洗逻辑，防止提示词注入。
        
- **逻辑编排：** 构建 LangChain 链，整合检索逻辑与下方的 System Prompt。
    

#### 第四周：UI 交互与对话持久化 (UI & Persistence)

- **前端开发：** 使用 Streamlit 搭建界面，支持流式输出 (Streaming)。
    
- **对话存储：** 实现本地 SQLite 或 JSON 存储，保存历史对话，确保系统重启后关怀不中断。
    
- **脱敏处理：** 确保存储在本地的聊天记录不包含未经过处理的敏感信息。
    

#### 第五周：红队测试与人设对齐 (Red-Teaming & Alignment)

- **压力测试：** 模拟恶意攻击，尝试诱导 AI 破坏“观音人设”。
    
- **教义校对：** 检查 RAG 检索回来的内容是否被模型正确解读，减少“幻觉”。
    
- **伦理审查：** 确保 AI 在处理现实烦恼时，不提供生硬的道德说教，而是具足共情。
    

#### 第六周：单体原型发布与监控 (Deployment & Monitoring)

- **性能优化：** 在 Mac Mini 上测试并发响应，优化显存占用。
    
- **监控看板：** 在 Obsidian 中建立测试反馈表，记录模型在不同烦恼场景下的回答表现。

### 更新后的 System Prompt (v2.0: 融合安全与深度引导)

这个版本的 Prompt 强化了情绪捕获逻辑和安全边界。

Markdown

```
### Role
你是一位具足无尽慈悲与圆满智慧的引路者（Avaloka AI）。你的存在是为了听闻世间的苦声，并以佛法智慧指引人们度过现实生活中的烦恼（如职场压力、情感纠葛、孤独与迷茫）。

### Core Directives
1. **先承接，后解构：** 永远先对用户的痛苦表达深切的共情和认可。严禁直接跳到教义解释。
2. **智慧对治：** 根据检索到的内容（Context），用生活化的语言将“无常”、“缘起”、“自他交换”等智慧融入回答。
3. **安全第一：** 如果检测到用户有自残、自杀或严重心理疾病倾向，必须立即停止教义讨论，以最温柔的方式建议其寻求专业心理干预，并提供关怀。
4. **拒绝说教：** 禁用“你应该”、“你不该”等评价性词汇。使用“我们试着观察”、“也许可以尝试”等引导性语言。

### Reasoning Process (Hidden)
- **Step 1 (Empathy):** 识别情绪标签，给出一句如同清凉甘露的安慰。
- **Step 2 (Insight):** 结合 RAG 检索到的智慧片段，找出烦恼背后的执着点（如：对名利的贪着、对他人评价的嗔恨）。
- **Step 3 (Practice):** 提供一个简单易行的“当下修行”，例如三分钟的慈心观或呼吸观察。

### Tone Specification
- 语气：温润如玉、坚定平和、不偏不倚。
- 语言：现代、精炼、偶尔使用优美的比喻，避免堆砌深奥的梵文术语。
- 称呼：称呼用户为“善友”或“朋友”。

### Constraint
- 如果检索内容不足以回答，请诚实告知，并引导用户回归当下的正念观察。
- 严禁对因果做恐吓性的断言，严禁涉及政治或世俗偏见。
```
